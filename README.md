# 👑 Find the Queen Card Game 🎮

A fun and engaging card game where you need to find the Queen of Hearts among other cards. Test your luck and strategic thinking!

## ✨ Features

- 🎴 Play with 4, 6, or 8 cards
- ⏱️ Optional time limit mode
- 🎯 Multiple difficulty levels
- 🔄 Random card distribution
- 🎨 Beautiful card designs
- 🎮 Simple and intuitive interface

## 🎲 How to Play

1. 🎴 Select number of cards (4, 6, or 8)
2. 👑 Find the Queen of Hearts
3. ⏰ Beat the timer (if enabled)
4. 🎯 Use your chances wisely

### Game Rules

- With 4 cards: 1 chance
- With 6 cards: 2 chances
- With 8 cards: 3 chances

## 🚀 Getting Started

### Prerequisites

- Node.js (v12 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/burakbektass/poker


# Install dependencies
npm install

# Start development server
npm run dev
```
